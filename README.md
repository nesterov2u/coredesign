# CoreDesign

Нативный прототип на SwiftUI для macOS 14 и новее.

## Сборка

Запустите `./build-app.sh` на Mac с Xcode Command Line Tools. Скрипт соберёт `CoreDesign.app` для архитектуры этого Mac. Sparkle загружается из закреплённого релиза и проверяется по SHA-256. Для сборки без сетевого доступа передайте путь к оригинальному архиву через `SPARKLE_ARCHIVE`.

По умолчанию сборка использует локальную подпись. Для распространения укажите `COREDESIGN_CODESIGN_IDENTITY` с сертификатом Developer ID Application и нотаризуйте приложение перед упаковкой.

## Обновления

В приложении откройте **CoreDesign → Проверить обновления…**. Sparkle читает `appcast.xml` из последнего GitHub Release и проверяет подпись архива перед распаковкой. Установка запускается по подтверждению пользователя.

Для выпуска задайте `COREDESIGN_VERSION` и возрастающий `COREDESIGN_BUILD_NUMBER` при сборке. Запустите `scripts/package-release.sh /путь/CoreDesign.app /путь/к/релизу`. Скрипт использует закрытый ключ из `COREDESIGN_SIGNING_KEY` или локального `.release-signing/update.key`. Опубликуйте полученные ZIP и `appcast.xml` как assets релиза с тегом `v<версия>`. Для чтения текущего релиза работает только публичный URL, авторизация в приложении не нужна.

Публичный ключ обновлений находится в `scripts/update-public-key.txt`. Закрытый ключ хранится у выпускающей стороны. Для следующих релизов нужен тот же ключ.
